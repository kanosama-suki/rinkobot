当前边界

R1.5 独立运行边界

  • 一次性登录地址换取短期 HttpOnly 会话
  • 单次模型调用返回一个 JSON 信封
  • 正文仍然逐字流式显示
  • 所有者 QQ 私聊与网页共用同一会话
  • 其他私聊和群聊只读汇总，不进入我们的上下文
  • 非所有者会话不读写所有者长期记忆
  • 网页普通回复不会自动推送到 QQ
  • 历史按 50 条游标分页，不一次性铺开
  • 记忆候选复用引用、敏感和去重门禁
  • 心情与承诺写入版本化状态事件
  • 图片由独立、可配置的视觉模型转述
  • 唯一调度循环处理计划、提醒和主动消息
  • 明确委托的提醒会自动进入发送队列
  • 模糊提醒才需要在聊天或面板里确认
  • 安静时段不发主动消息，但提醒照常送达
  • 私人摘要只在登录后的所有者面板显示
