# Historical material

This directory is reserved for historical milestone records and research that
are no longer part of the current product contract.

The R1.5 decoupling removed the DSH plugin entry point, the DSH model provider,
and the DSH-specific UI. The complete pre-decoupling code is recoverable from
the annotated tag `archive/dsh-plugin-0.20.0`.

The historical plugin catalog lives here. Older M-series files still live in
`docs/` for now because older planning records link to them directly. They
describe the former plugin era and are not current installation or architecture
instructions.

`Kanobot` was the project's former name. Historical records keep the name used
at the time; the current product brand is `Rinkobot`.
