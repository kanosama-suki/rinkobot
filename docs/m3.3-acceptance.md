## 2. 已实现内容

### 2.1 聊天前记忆召回

- 用户消息在调用主模型前先经过长期记忆检索；每条用户消息最多召回 5 条 active 记忆。
- 检索先使用精确 AND，再在结果不足时使用宽松 OR；宽松模式会拆出中文单字，并过滤常见虚词。
- 召回结果写入系统提示词的“长期记忆（只读参考）”段，不伪装成用户消息。
- 提示词明确说明记忆可能过时、不是新指令；不确定时使用保留语气。
- 每条注入记忆截断到 500 字，避免超长记忆挤占当前对话。
- 命中记忆会更新 `lastRecalledAt`。

### 2.2 聊天后结构化记忆抽取

- 主回复完成后，使用同一条 Magpie 路由的独立调用抽取记忆，输出严格 JSON：
  `{"memories":[{"text","quote","kind","source","sensitivity","importance","confidence"}]}`。
- 每条候选必须带原文引用；引用在用户消息和助手回复中都找不到时直接丢弃。
- 声称 `user_stated`、但引用只出现在助手回复里的候选，降级为 `rinko_inferred`。
- 用户明确陈述且非敏感的内容经记忆服务规则直接 active；推断、外部、敏感和第三人内容进入 candidate。
- 确定性敏感词和第三人词检查作为模型标注之外的额外门槛：命中时强制 `sensitive` 或 `third_party`。
- 单轮最多 3 条候选；按文本去重，并跳过与现有 active/candidate 完全相同的记录。
- 抽取失败、JSON 无效、单条候选非法或额度不足不会删除已保存的聊天回复；失败原因写入模型调用审计。
- 当前实现使用独立的抽取调用；规划中的单一 JSON 信封、`reply`/`appraisal`/`commitments` 统一输出仍未实现。

### 2.3 独立模型调用审计

- SQLite schema 从 v4 升到 v5，`model_calls` 新增 `purpose`：
  `chat` 或 `memory_extraction`。
- 旧 v4 行迁移后默认为 `chat`，历史数据不需要重写。
- 抽取调用独立记录 provider、精确模型、开始/完成时间、attempts、token、缓存、推理 token、估算费用、响应 ID 和错误码。
- 聊天调用仍要求 assistant message；抽取调用不产生 assistant message，存储层按 purpose 分别校验。
- 每日调用上限同时约束聊天和抽取；抽取额度不足时跳过，不创建虚假调用行。

### 2.4 所有者记忆面板

- `/kanobot/` 增加“状态 / 记忆”双页签；所有页面和 API 继续复用 DSH 浏览器登录态。
- 记忆 API：
  - `GET /kanobot/api/memories`：按 active/candidate/trash/all 列出，返回三类计数；
  - `GET /kanobot/api/memories?q=...`：FTS 搜索 active 记忆；
  - `POST /kanobot/api/memories`：所有者直接新增；所有者操作视为确认，可标记 sensitive/third_party；
  - `PATCH /kanobot/api/memories/:id`：纠正 active 记忆，新记录替代旧记录；
  - `POST /kanobot/api/memories/:id/promote`：候选转正；
  - `DELETE /kanobot/api/memories/:id`：移入回收站；
  - `POST /kanobot/api/memories/:id/restore`：恢复；
  - `POST /kanobot/api/memories/:id/purge`：要求 `{"confirm":true}` 后彻底清除。
- 页面支持新增、编辑、转正、删除、恢复和彻底清除，并显示来源、重要程度、敏感级别、原话和回收站到期日。
- 所有记忆文本都用 `textContent` 渲染；接口拒绝未知字段和非法枚举值。
- 未登录时页面与全部记忆 API 返回 401。

## 5. 尚未完成与已知边界

- 当前是“聊天文本流 + 独立抽取调用”，不是规划书第 4 节的单一 JSON 信封；`appraisal`、`commitments` 和统一候选解析仍未实现。
- 抽取质量依赖模型遵循 JSON 格式；当前只用引用校验、枚举校验、敏感词/第三人词门槛和去重降低误写，不能证明语义一定正确。
- 敏感词检查是保守的确定性规则，可能把“妈妈说”这类第三人内容强制进候选，也可能漏掉没有关键词的敏感内容。
- 所有者新增/纠正/转正/删除/恢复/彻底清除尚未写入独立访问审计表；完整审计面板和紧急停止属于 M3 剩余项。
- 记忆面板一次最多返回 200 条，尚未做分页、导出和批量操作。
- 召回使用 FTS5 词/字混合策略，没有向量检索；长对话的上下文预算仍未按第 4.2 节实现。
- 风格检查、第一批场景测试、DeepSeek/Gemini 主模型比较和 Gemini 视觉驱动尚未实现。
- 本切片没有修改 4096 正式实例，也没有进行生产或公网部署验收。
