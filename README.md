# Kanobot

一个运行在 DSH 宿主中的陪伴型自进化机器人。她同时是家人、恋人和生活协助者，目标不是做一个套着人格外壳的通用任务代理，而是建立连续、可恢复、可审计的长期关系。

> 当前状态：M4 已开始，第 0 步“记忆质量门控”已完成（2026-11-06）。仓库里已有可运行的 DSH Host 插件和不经过 DSH 的本地开发入口、严格配置加载器、版本化事件与纯 reducer、SQLite 持久化、确定性快照、回收站/彻底清除、独立墓碑库、每日备份、复用 DSH 登录态的网页聊天和 SSE 流、连接本地 Magpie 的精确模型网关与调用审计、FTS5 双列中文检索、聊天前记忆召回注入、记忆问题意图/相关性门槛/重复抑制、显式“记住这个”兜底、单次模型调用返回的 `reply`/`memoryCandidates`/`appraisal`/`commitments` 信封、正文逐字流式显示、appraisal 状态事件、承诺正文与事件、所有者记忆面板、确定性回复风格检查与一次自动重写、跨聊天/记忆/模型/风格/所有者的统一审计时间线、紧急停止/`STOP` 文件双重开关、当前时间/星期/沉默时长/定性状态和分块上下文预算，以及独立可配置的视觉模型。对话仍使用占位人格；M4 调度器、生活事件、主动消息、提醒和每日整理尚未实现。边界与证据见 [M3.0](docs/m3-acceptance.md) 到 [M3.7](docs/m3.7-acceptance.md)、[M3 收尾验收](docs/m3-completion-acceptance.md) 和 [M4.0 记忆验收](docs/m4.0-memory-acceptance.md)。

## 本地开发

```powershell
npm install
npm run dev
```

默认只监听 `127.0.0.1:4101`，使用 `config/examples`、`tmp/dev-data` 和 mock 模型。终端会打印一次性登录地址；页面和 API 都需要这次登录换取的短期会话。确认配置在 Git 外后，可用 `npm run dev -- --config <配置目录> --data <数据目录> --model-mode magpie` 连接本机 Magpie。

## 当前确定的方向

- DSH 作为宿主，陪伴核心、状态、记忆、主动性和进化治理自行开发；发行形态是同一核心 + DSH 插件 + 独立程序，不维护两套人格/记忆。
- 不使用巨型 FSM；采用事件驱动状态、纯 reducer、策略层、事件日志和快照。
- 人格是燐子（rinko），设定放在 Git 外；仓库里的示例和测试只用占位身份。
- 先在本地 Windows 上开发和使用，之后迁移到 Linux 服务器；主模型选型后置到项目完工后，视觉模型独立配置且不写死厂商或模型名；M3 基线通过本机 Magpie 路由，发行前（M4.5）增加 DSH 宿主模型和受控第三方 OpenAI-compatible API。
- 第一个可以日常使用的版本是 M4：网页聊天、长期记忆、每日整理、每 1～2 小时主动一次和提醒；M4.5 再补双形态和发行基础。
- 个人 QQ + NapCat 后置，用户已接受风控/封号风险；工程上仍做白名单、限频、去重和熔断。
- 公开发送和每轮 LLM 审查整体后置；发布前会用真实模型跑人格场景评测，平台违禁词另做渠道策略。
- 记忆按“相关性优先”召回；显式“记住这个”必须有确定性兜底，普通寒暄不自动永久化；重要度不能压过当前问题主题。
- 她可以偶尔主动提起自然相关的旧事；长时间未回复的关心不能按固定小时数写死；软性日常安排由她自己调整。
- 配置按模块拆分，一个功能模块一个 TOML 文件；个人配置和凭据不进入 Git。
- Linux 桌面 VM、浏览器阅读、单机游戏和受控自进化按里程碑逐步验证。
- 状态由版本化事件和纯 reducer 驱动；快照可重复回放，数据库损坏或 schema 不兼容时拒绝启动。
- 主库备份不包含独立墓碑库；恢复旧主库后先重放墓碑，旧删除内容不会复活。

## 不承诺的事情

- 当前是可本地链接进 DSH 测试 Profile 的私有开发包，不是已发布的可安装版本；准备发行，但发行门禁是 M4.5。
- M3 的视觉能力只覆盖“独立模型读取单张图片并转述，再交给主聊天模型”的当轮闭环；图片不落库，视觉失败不会伪造描述或静默降级。自动测试不调用真实模型，场景测试仍使用脚本化占位回复；真实模型比较、主模型选型和生产部署尚未完成。
- 本地开发入口只用于调试，默认 mock、临时数据、回环监听和一次性短期会话；它不是第二产品形态，不能替代 DSH 正式登录和部署边界。
- 不保证个人 QQ/NapCat 长期稳定，不保证不被平台风控。
- 不把第三方插件的 README、测试数量或收录状态当作安全审计。
- 不把虚拟身体状态当成真实生理状态，也不把关系数值当成用户价值评分。
- 数据库文件扫描不等于 SSD、文件系统快照、云备份或模型服务商侧的物理擦除。
